# Generated task programs

Standalone Python programs emitted by the reference compiler for the 54 synthetic tasks.

Each task has three versions: `v1` translates written instructions, `v2` adds an exception formula inferred from resolved cases, and `v3` adds piecewise refinement where supported. The filename contains the occupation/task identifier and compiler version. These files are generated artifacts; the compiler implementation is in `src/compiler_agent.py`.
