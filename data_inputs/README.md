# Input data

Task specifications, occupational attributes, and empirical reference material used by the laboratory.

| File or folder | Contents |
| --- | --- |
| `onet31_tasks_lab18.csv` | O*NET task statements for the 18 reference occupations |
| `onet31_tasks_proposed_additions.csv` | Task statements for additional occupations |
| `onet31_tasks_to_dwas_lab18_and_additions.csv` | Task mappings to detailed work activities |
| `proposed_additional_occupations.csv`, `proposed_corpus_tasks.csv` | Expanded occupation and task specifications |
| `lab18_closure_values.csv` | Occupational attributes mapped to the reference corpus |
| `closure_native_soc2018_codes.csv` | Attributes at the native SOC-2018 occupation level |
| `closure_table_units_753.csv` | Attributes for 753 harmonized occupational units |
| `CODEBOOK_closure_native.csv`, `CODEBOOK_closure_units.csv` | Variable definitions and sources for the closure tables |
| `macro_outcomes.csv`, `macro_outcomes_extended_lab54.csv` | Occupational outcomes mapped to the laboratory's tasks |
| `empirical/` | Supporting empirical estimates and notes for descriptive comparisons |
| `drafted_rulebooks/` | Additional structured rulebook specifications |

Source columns identify the datasets and vintages. Occupational outcomes repeated across tasks retain the occupation or harmonized source unit as their measurement level. Some occupations share source values; task rows are not independent empirical observations.

Licensing shares, hand-coded sign-off indicators, and statutory task reservations are distinct measures. The laboratory's task-level sign-off assignments and synthetic case rules are research specifications. Empirical comparisons do not independently validate those specifications. See the technical appendix and prospective validation protocol for interpretation.
