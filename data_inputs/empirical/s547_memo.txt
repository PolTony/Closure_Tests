VERDICT (pre-specified): PARTIAL.
  Massenkoff        b = -0.0592 (SE 0.0120), t -4.95, wild-bootstrap p .010, -73% of the same occupations' non-sign-off mean
  AEI Jun-2026      b = -0.00248 (SE 0.00146), t -1.70, wild-bootstrap p .089, -53%
  The rule needs b < 0 with |t| >= 2 on both outcomes. Massenkoff meets it. AEI June 2026 has the right sign and a large

    dictionary passed on Massenkoff only, and the STRICT sign/certify/approve/authorize/attest/prescribe dictionary passed on
    both platforms. This is therefore a confirmatory re-test of a construct selected on G1 data. It is not a fresh
    pre-registration.
  - Fixed before any outcome regression with the new label: the label, the threshold rule, the specification, the outcomes
    and the verdict rule.
  - The training labels are LANGUAGE-MODEL codes (this agent, reading 2,000 statements blind to stratum and dictionary flags).
    They are not human codes.

4. ELOUNDOU FEASIBILITY (robustness row; the file was approved by the author)
   Data: data/external/eloundou_task_labels/full_labelset.tsv. Task ID matches 27.0 100%, with identical text.
   Within occupation, sign-off tasks are rated MORE feasible by GPT-4 (E2 +0.14, beta +0.08). Human ratings are about equal
   (E1 -0.04, E2 +0.005). So the Massenkoff gap is not an artefact of a low feasibility gate.
     Massenkoff: primary -73%; + human and GPT-4 E1/E2 indicators -81% (t -5.15, boot .006); + GPT-4 beta -78% (t -5.08,
       boot .009)
     AEI Jun-2026: primary -53%; + E-level indicators -39% (t -1.30, boot .13); + beta -53% (t -1.56, boot .12)
   The joint row equals the E-level row, because beta (= GPT-4 E1 + 0.5 E2) is collinear with the GPT-4 dummies. A first
   bootstrap that included the collinear term gave a spurious p of .14 and was rerun without it.
   Post hoc: on tasks with beta > 0 only, Massenkoff is -48% (t -3.10) and AEI June is -7% (t -0.18).

5. POST-HOC CHECKS (written after the results above were seen; not part of the verdict)
   PPML (relative effects, occupation FE, SOC-3 clusters):
     Massenkoff -71% (t -2.11); AEI Jun-2026 -79% (t -2.22); Aug -79% (t -2.85); Nov -69% (t -2.91); Feb -65% (t -2.40);
     pooled -70% (t -2.83); first-party API -87% (t -4.34)
   The linear AEI share regression is dominated by a few occupations with heavy use of their other tasks. In the linear model
   the gap is concentrated where base use is above the median (Q1 x high-base -0.0073, t -3.0). One example: the editors'
   "approve" task has 0 use against 0.096 for the editors' other tasks.
   The AEI June miss on the pre-specified linear specification is therefore a precision problem, not a sign problem. The
   verdict stays PARTIAL as pre-specified.

6. CLASSIFIER QUALITY (Script 546; cross-validated against LANGUAGE-MODEL labels)
   Training sample (excluding the 360 human-packet items):
     - 700 tasks with the highest MiniLM similarity to the strict centroid
     - 500 dictionary positives
     - 800 random tasks
   Labels: Q1 79 positives, Q2 303.
   Features: MiniLM (384) + TF-IDF word 1-3 grams + s540 pattern indicators. Model: L2 logistic regression; C = 30, chosen by
   CV log-loss.
   Q1 threshold 0.44 = maximum CV F1 subject to CV precision >= .85, fixed before any outcome regression.
     Q1 out-of-fold, population-weighted: precision .974, recall .751, F1 .848, AUC .986
     Q1 out-of-fold, unweighted sample: precision .974, recall .949
     Q1 dictionary STRICT, population-weighted: precision .978, recall .450
     Q2: precision .920, recall .709, AUC .946; dictionary PRIMARY recall .264
   Counts: the classifier flags 177 tasks for Q1 (0.92%; strict 135; overlap 133) and 533 for Q2 (2.77%).
   Limits:
     - The population recall rests on ONE random-stratum Q1 positive (a "discharge patients" task coded unsure), so it is very
       imprecise.
     - Among the 16,905 tasks in neither training nor packet, the classifier flags 1 Q1 task, and that one is a false positive.
     - My random stratum implies roughly 20 (range about 1-120) sign-off tasks phrased in words neither tool finds.
     - The classifier is in effect the strict dictionary plus the order, issue and admit/discharge acts.
